# MyConcert

## 프로젝트 소개

**MyConcert**는 좋아하는 아티스트의 공연과 지역별 공연 정보를 한곳에서 탐색할 수 있는 Android 애플리케이션입니다. KOPIS(공연예술통합전산망) OpenAPI를 활용해 공연 일정, 출연진, 공연장, 예매처 정보를 모아 제공합니다.

아티스트마다 흩어져 있는 공연 소식을 찾아보는 번거로움을 줄이고, 관심 있는 아티스트와 지역을 중심으로 관람할 공연을 발견할 수 있도록 제작했습니다. 공연명 검색 결과에 출연진 검증을 더해 이름이 비슷한 다른 공연이 섞이는 문제도 줄였습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 아티스트 공연 탐색 | 한글·영문 이름으로 아티스트를 검색하고 예정 공연과 이전 공연을 확인합니다. |
| 선호 아티스트 모아보기 | 최대 8팀을 선호 아티스트로 등록하고, 홈에서 공연 일정을 모아봅니다. |
| 지역별 공연 탐색 | 전국 17개 지역 지도에서 지역을 선택해 대중음악·복합 장르 공연을 조회합니다. 위치 권한을 허용하면 현재 위치에 맞는 지역을 선택할 수 있습니다. |
| 조회 기간 선택 | 30일·90일·180일·365일 단위로 조회 범위를 조절합니다. 아티스트 공연은 최근·향후 기간을, 지역별 공연은 향후 기간을 조회합니다. |
| 축제·공동 공연 탐색 | 확장 검색으로 공연명에 아티스트 이름이 없는 축제와 공동 공연의 출연진까지 확인합니다. |
| 미등록 아티스트 직접 검색 | 기본 목록에 없는 아티스트도 이름으로 검색하고, 검색명을 저장·편집하거나 직접 추가한 아티스트를 삭제할 수 있습니다. |
| 공연 상세 확인 | 포스터, 공연 기간, 공연장, 출연진, 공연 시간, 관람 연령, 가격과 KOPIS가 제공하는 예매처 링크를 확인합니다. |
| 일정 저장·공유 | 캘린더 앱으로 공연 일정을 추가하고 공연명·기간·장소·링크를 공유합니다. |
| 개인화·편의 기능 | 최근 검색 기록 확인·삭제, 라이트·다크 모드, 새로고침과 조회 중단을 지원합니다. |

## 이용 흐름

1. **관심 아티스트 선택** — 처음 실행할 때 선호 아티스트를 선택하거나, 홈에서 나중에 추가합니다.
2. **공연 탐색** — 아티스트를 검색하거나 지역 지도에서 관심 지역을 선택합니다.
3. **조회 범위 조절** — 기간을 변경하고, 필요하면 축제·공동 공연까지 확장 검색합니다.
4. **상세 확인 및 활용** — 공연 정보를 확인한 뒤 예매처로 이동하거나 캘린더에 일정을 추가하고 공유합니다.

## 주요 세부 로직

### 1. 검색명 정규화와 표기 차이 처리

아티스트의 한글·영문 공식명과 별칭을 검색 사전으로 관리합니다. 입력값에는 **유니코드 NFKC 정규화**, 영문 소문자 변환, 공백과 일부 구분 기호 정리를 적용해 같은 이름의 표기 차이를 줄입니다. 목록 검색에서는 정규화한 이름이 완전히 일치하는 아티스트를 우선 표시합니다.

| 상황 | 예시 | 처리 방식 |
| --- | --- | --- |
| 한글·영문 이름 차이 | `아이브` / `IVE` | 사전에 등록된 같은 아티스트의 공식 표기로 연결 |
| 대소문자·띄어쓰기 차이 | `day 6` / `DAY6` | 정규화한 이름을 기준으로 검색 |
| 전각·반각 문자 차이 | `ＱＷＥＲ` / `QWER` | NFKC 정규화로 동일하게 처리 |
| 구분 기호 차이 | `DAY-6` / `DAY6` | 공백·하이픈 등 일부 구분 기호를 정리 |
| 다른 단어 안에 포함된 이름 | `IVE` / `LIVE`, `IU` / `PREMIUM` | 공연명·출연진 검증 시 단어 경계를 확인해 오탐 방지 |

### 2. 공연 후보 조회와 출연 여부 검증

KOPIS 공연명 검색은 부분 일치 방식이므로, 검색 결과를 그대로 특정 아티스트의 공연으로 확정하면 관련 없는 공연이 포함될 수 있습니다. MyConcert는 다음 단계로 후보를 확인합니다.

1. 아티스트의 공식 표기·별칭·등록된 투어명으로 공연 후보를 조회합니다.
2. 공연명에서 이름의 단어 경계를 확인해 부분 문자열만 겹치는 후보를 걸러냅니다.
3. 후보의 상세 정보를 조회하고 공연명, 출연진, 장르를 함께 비교합니다.
4. 일치 근거가 있는 공연을 결과에 반영하고, 판단이 불확실한 후보는 제외 건수를 안내합니다.

출연 여부를 판별할 때는 다음 규칙을 적용합니다.

- **그룹과 멤버 구분:** 출연진의 그룹 공식명 또는 서로 다른 멤버 2명 이상의 일치를 확인합니다. 한 멤버의 예명·실명은 같은 사람으로 계산하며, 멤버 개인의 솔로 공연·단독 팬미팅은 그룹 공연에서 제외합니다.
- **동명이의어 구분:** `JIN`과 `KWON JIN AH`, 그룹명 `아이들`과 일반 명사 `아이들`처럼 모호한 표기는 추가 근거를 확인합니다.
- **간접 관련 공연 제외:** 커버·헌정·트리뷰트·실황 상영 공연은 해당 아티스트의 출연 공연에서 제외합니다.
- **불확실한 정보 구분:** 투어명만 일치하거나 다른 장르의 동명 공연인 경우, 추가 근거 없이 출연을 확정하지 않습니다. 상세 조회에 실패한 후보도 확정 결과에서 제외합니다.

### 3. 축제·공동 공연 확장 검색

기본 검색은 공연명에 공식명이나 등록된 투어명이 있는 후보를 찾습니다. **‘축제·공동 공연의 출연진까지 검색’**을 켜면 조회 기간의 대중음악·복합 장르 공연을 수집하고 상세 출연진을 검증합니다.

이를 통해 공연명에 아티스트 이름이 없는 행사도 찾을 수 있습니다. 확인할 후보가 많아질 수 있어 진행 상태를 표시하고 사용자가 조회를 중단할 수 있도록 했습니다.

### 4. 직접 검색과 검색명 관리

- 기본 목록에 없는 아티스트도 입력한 이름으로 검색합니다. 빈 입력, 기호만 있는 이름, `콘서트`·`LIVE` 같은 일반 공연 분류어는 입력 단계에서 확인합니다.
- 정규화한 이름으로 고유 ID를 생성해 대소문자·띄어쓰기만 다른 직접 검색이 중복 등록되는 것을 줄입니다.
- 일치 공연을 확인한 직접 검색 아티스트는 기기에 저장합니다. 출연진에 `실리카겔(Silica Gel)`처럼 한글·영문 이름이 명시적으로 함께 표기된 경우에는 해당 표기를 검색명에 추가합니다.
- 직접 추가한 아티스트의 검색명은 1~8개로 편집할 수 있습니다. 다른 아티스트에 이미 등록된 이름과 중복되는지 확인합니다.

### 5. 지역·기간별 데이터 처리

지역별 탐색에서는 선택한 지역의 대중음악·복합 장르 공연을 조회합니다. API 지역 코드가 통합된 광주·전남은 관련 코드를 함께 조회한 뒤 공연시설 주소를 확인해 사용자가 선택한 지역으로 분류합니다.

조회 기간은 요청당 최대 31일 구간으로 나누고, 각 구간을 페이지당 100건씩 조회합니다. 여러 검색명·기간·페이지에서 반복 수집된 공연은 **KOPIS 공연 ID**로 중복을 제거합니다. 한국 시간을 기준으로 진행 중인 공연과 예정 공연을 함께 표시하며, 종료된 공연은 이전 공연으로 구분합니다.

## 데이터 조회 및 저장

- **응답 캐시:** 공연 목록은 15분, 상세 정보는 24시간 동안 저장된 응답을 재사용해 반복 요청을 줄입니다.
- **연결 실패 대응:** 기존에 저장된 응답이 있으면 해당 정보를 표시하고, 저장된 정보라는 안내와 시각을 제공합니다.
- **새로고침:** 캐시 유효기간과 관계없이 API에 다시 요청합니다.
- **요청 제어:** 요청 간 간격을 두고 일시적 서버 오류를 최대 2회 재시도합니다. 화면 이동이나 새 조회가 시작되면 이전 조회를 취소합니다.
- **결과 상태 안내:** 빈 결과, 조회 실패, 일부 요청 실패, 조회량 제한을 구분해 표시합니다.
- **사용자 설정 저장:** 선호 아티스트, 최근 검색 기록, 직접 등록한 검색명, 선택 지역과 테마를 기기에 저장합니다.

공연 정보는 **KOPIS에 등록된 데이터**를 기준으로 합니다. 미등록 공연, 출연진이 누락된 행사, 검색 사전에 없는 표기는 조회에서 누락될 수 있습니다. 예매처 링크와 상세 항목도 KOPIS가 제공하는 범위에서 표시합니다.
