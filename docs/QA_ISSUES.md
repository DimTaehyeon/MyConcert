# MyConcert QA 관리표

사용자가 요청한 수정은 바로 반영합니다. 추가 테스트로 새로 발견한 문제는 재현 조건과 영향을 먼저 보고하고, 수정 여부를 기록한 뒤 처리합니다.

상태: `수정 중` → `재검증` → `완료`, 추가 발견 항목은 `검토 대기` → `수정 예정` 또는 `보류`.
