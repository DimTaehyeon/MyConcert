# 2차 QA — MyConcert 1.2

## 앱 변경

- 내 아티스트의 예정 공연 제목 아래 **조회 : 향후 30일 기준**, 이전 공연 이력 아래 **조회 : 최근 30일 기준**을 표시합니다. 선택한 90·180·365일에도 같은 값이 반영됩니다. 개별 아티스트·전체 목록·지역 목록에도 현재 조회 기간을 표시합니다.
- 사전 등록되지 않은 이름도 아티스트 검색 화면에서 **공연 직접 검색**으로 조회합니다. 키보드 검색 버튼으로도 제출할 수 있습니다. 입력한 이름과 KOPIS의 공연명·출연진을 비교해, 일치 결과가 확인되면 검색명을 이 기기에 저장합니다.
- 저장한 이름은 **내가 추가한 아티스트**와 최근 검색에 표시되며, 선호 아티스트에 추가할 수 있습니다. 아티스트 화면의 **검색 표기 → 검색명 편집**에서 같은 아티스트의 한글·영문 이름을 최대 8개 저장하고 다시 조회할 수 있습니다. 사전 검증된 기본 아티스트의 검색 사전은 유지합니다.
- 자동 학습은 출연진 한 항목이 명시적으로 한글·영문 이름을 함께 표시한 경우에만 다른 언어의 이름을 추출합니다. 그룹 멤버 각각의 이름, 공연장 이름, 투어명, 보컬 등 역할은 그룹 검색명으로 저장하지 않습니다. 결과가 없거나 통신 오류가 난 검색어를 확인된 이름으로 표시하지 않습니다. 결과가 없어도 사용자가 검색명을 편집하거나 선호 아티스트로 지정하면 미확인 상태로 저장할 수 있습니다.
- **공연 더 보기**는 카드 목록 전용 영역 안에서만 결과를 추가합니다. 조회 시각·새로고침·크레딧은 그 영역 뒤에 있어, 추가된 카드 사이로 새로고침 버튼이 들어가지 않습니다.
- 400dp 이상 내려가면 오른쪽 아래에 **↑ 맨 위로** 버튼이 표시됩니다. 누르면 해당 화면의 맨 위로 이동합니다. 하단 여백을 확보해 크레딧을 가리지 않도록 했습니다.

## 실제 API 확인

최근·향후 30일(2026-10-12~2026-12-11) 조건으로 기존 48팀 사전에 없던 이름을 조회했습니다.

| 직접 입력한 이름 | 원본 목록 응답 | 확인 내용 |
|---|---:|---|
| 터치드 | 1건 | `여전히 소란스럽게 Vol.03 노브레인 with 안예은, 터치드`, 2026-11-13, 무신사 개러지 |
| 브로콜리너마저 | 4건 | 전국 인디 교류 투어 서울·춘천·세종·부산, 2026년 10월 |
| 실리카겔 / Silica Gel / QWER / TOUCHED / 한로로 / HANRORO | 각각 0건 | 해당 입력 표기·조사 기간의 응답이 없었습니다. 아티스트가 존재하지 않거나 모든 공연이 없다는 뜻은 아닙니다. |

실제 응답: [qa-artist-discovery.json](qa-artist-discovery.json). 터치드·브로콜리너마저의 원본 상세 응답을 앱과 동일한 매칭 규칙으로 검증했습니다. 전산망에 미등록된 일정이나 다른 표기로 등록된 공연까지 자동으로 확인할 수는 없으므로, 기간 변경과 검색명 편집을 지원합니다.

## Figma 반영

새 파일을 만들지 않고 [기존 MyConcert 파일](https://www.figma.com/design/D7NNqJrQzDyFViSuVjaCfX/MyConcert?node-id=1-9)을 업데이트했습니다.

- 기존 홈, 아티스트 검색, 예정·이전 공연 목록, 예정 1건 상태, 지역 선택의 **6개 프레임을 같은 ID로 수정**했습니다.
- 직접 검색, 검색명 저장 후 아티스트 공연, 검색명 편집 대화상자, 초기 설정, 선호 편집, 상세, 다크모드, 목록 하단을 추가해 **14개 앱 화면**을 반영했습니다.
- 텍스트·아이콘·지도·카드는 편집 가능한 레이어와 컴포넌트입니다. 완성 화면 스크린샷을 디자인 레이어로 넣지 않았습니다. 로고와 실제 KOPIS 공연 포스터만 이미지 자산을 사용했습니다.
- Android의 Roboto·Noto Sans KR 글꼴과 앱의 색상·간격을 반영했습니다. 공통 카드·아티스트 행·안내·크레딧, Material 텍스트 버튼을 재사용합니다. 라이트·다크 색상 변수를 연결했습니다.
- 화면 렌더링을 확인하고 공통 컴포넌트 높이, 크레딧 줄 겹침, 다크모드 뒤로가기, 상세 포스터, 스크롤 하단 버튼 배치를 보정했습니다.

주요 프레임: 홈 `1:9`, 검색 `2003:228`, 지역 `2011:20`, 직접 검색 `2026:588`, 검색 결과 `2026:623`, 검색명 편집 `2026:1302`, 목록 하단 `2026:1071`.

## 검증 상태

- 버전 **1.2**, versionCode **3**.
- 단위·실제 API 표본 테스트 **38개 통과**, 실패·오류 0건.
- APK 빌드와 Android Lint 검사 통과, Lint 오류 0건.
- 카드 추가 후 새로고침 위치, 맨 위로 이동, 직접 검색 진입, 저장한 검색명의 재실행 유지에 대한 기기 테스트를 추가하고 빌드했습니다.
- 현재 연결된 Android 기기가 없어 이 기기 테스트의 실제 터치 실행은 확인하지 못했습니다. Figma 렌더링 검증과 앱 빌드·단위 테스트 결과를 구분합니다.
