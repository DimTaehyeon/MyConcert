# QA 반영 — MyConcert 1.1

## 반영한 내용

1. **지도와 지역 위치**: 지도가 표시되는 실제 이미지 사각형을 기준으로 위치 점을 계산합니다. 원본 지도에 그려진 각 지역 경계 내부로 점을 보정했습니다. 버튼은 연결선으로 위치 점을 가리키며, 작은 화면에서는 버튼 크기를 조절합니다. 248·288·340·600px 상당의 논리 화면 폭에서 버튼 겹침을 검사했습니다.
2. **선호 하트**: 글자 하트 대신 같은 형태의 채움·윤곽선 벡터 아이콘을 사용합니다. 해제 상태에도 두꺼운 윤곽선과 원형 배경·테두리가 유지됩니다. 48dp 버튼이며 선택 상태를 접근성 안내에 반영합니다. 토글 시 전체 화면을 다시 만들지 않습니다.
3. **광주·전남 누락**: 아래 실제 API 대조 결과에 따라 현재 통합 코드 조회와 공연장 주소 분류를 추가했습니다.
4. **현재 위치**: 지역 화면 첫 진입 시 위치 권한을 요청합니다. 권한을 허용하면 GPS·네트워크의 현재 위치를 시·도로 변환해 기본 선택합니다. 대략적 위치만 허용해도 네트워크 위치를 사용할 수 있습니다. 거부·위치 서비스 꺼짐·20초 시간 초과 시 기존 지역을 유지하고 지도 선택을 허용합니다. 직접 선택한 지역은 저장되며, 진행 중인 자동 위치 응답이 사용자의 선택을 덮어쓰지 않습니다. 이후에는 ‘내 위치’ 버튼으로 다시 찾을 수 있습니다. 위치 좌표는 저장하거나 KOPIS에 보내지 않습니다. 백그라운드 위치 권한은 요청하지 않습니다.
5. **크레딧**: 화면 하단에 ‘백석대학교 스마트폰프로그래밍 기말프로젝트의 일환으로 제작되었습니다.’와 ‘제작 · 첨단IT학부 빅데이터전공 / 20223468 김태현’을 표시합니다.

## 광주·전남 0건 조사

조회 조건은 **2026-11-11~2026-12-11, 대중음악(CCCD)·복합(EEEA), 공연명·아티스트 필터 없음**입니다.

| 요청 | 대중음악 | 복합 |
|---|---:|---:|
| 기존 광주 코드 29 | 0 | 0 |
| 기존 전남 코드 46 | 0 | 0 |
| 현재 통합 코드 12 | 10 | 2 |

전국 목록에도 동일한 통합 권역 12건이 있었습니다. 따라서 공연 부재나 아티스트 검색어 문제로 발생한 0건이 아닙니다. API 응답에서 해당 공연의 `area`가 `전남광주통합특별시`로 표시되었습니다. 현행 코드로 후보를 조회하고 상세 응답의 시설 ID(`mt10id`)로 공연장 주소를 조회해 다음과 같이 나눕니다.

| 앱의 탐색 권역 | 분류 기준 | 확인 건수 |
|---|---|---:|
| 광주권 | 동구·서구·남구·북구·광산구 소재 공연장 | **7** |
| 전남권 | 목포시·여수시 등 기존 전남 시·군 소재 공연장 | **5** |

예를 들어 V.O.S 공연은 북구 북문대로 60, 김건모 공연은 광산구 광주여대길 45로 광주권에 들어갑니다. 진성·조항조 공연은 목포시 부주로 312, 김장훈·변진섭 공연은 여수시 좌수영로 69로 전남권에 들어갑니다. 공연명에 ‘광주’라는 단어가 있는지만으로 분류하지 않습니다. 경기도 광주시는 경기도로 유지합니다. 주소 미등록·조회 실패는 제외 사유를 안내합니다.

통합 전 주소와 코드도 함께 지원합니다. 광주·전남 버튼은 사용자가 공연을 찾는 지리적 권역이며, 현재 행정구역 명칭과 API 반환 명칭은 다를 수 있습니다.

- 실제 요청·응답: [기존 코드와 전국 대조](qa-region-audit.json), [현행 코드와 시설 주소 대조](qa-region-migration.json)
- 공식 변경 안내: [행정표준코드관리시스템의 2026.7.1 전남광주통합특별시 법정동 변경 안내](https://www.code.go.kr/etc/index_iframe.do)
- 공식 지역 사이트: [전남광주통합특별시](https://www.jeonnam-gwangju.go.kr/)

## 확인 범위

- APK: 버전 **1.1**, versionCode **2**. 기존 설치본과 같은 앱 ID를 사용합니다.
- 단위·실제 API 표본 테스트 **32개 통과**, 실패 0건.
- Android Lint 오류 **0건**.
- 화면 흐름 테스트 빌드 완료. 하트 선택·해제·재선택과 크레딧 표시 검사를 추가했습니다.
- [지도 배치 미리보기](qa/map-layout-preview.png)는 앱과 같은 좌표·축척 계산으로 만든 배치 검토용 이미지이며, 실제 Android 기기 스크린샷은 아닙니다.
- 현재 연결된 Android 기기가 없어 실제 터치 및 GPS 권한 허용·거부 화면은 실행 확인하지 못했습니다. 해당 동작은 기기에서 추가 확인이 필요합니다.
